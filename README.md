# Danti Software

The Danti Software Ltd home page: square links to each project, in the Danti look
(the same colours, Geist fonts, mark and favicon as the Danti website). No build step: open `index.html`.

To add a project, copy an `<a class="project">` block in `index.html` and change the link, name and label.

Fonts: Geist, under the SIL Open Font License (`fonts/OFL-geist.txt`).
